  西南石油大学 — 测绘创新创业智能大赛训练系统
================================================================

【项目说明】
  本系统包含 56 道测绘程序设计训练题目，涵盖：
  - 上册：基础篇（出租车轨迹、IDW插值、最短路径、坐标转换等）
  - 下册：进阶篇 + 竞赛篇 + 创新篇（GNSS、水准网、基线解算等）
  - 真题：2022-2025 年竞赛真题
  
  每题配有题目描述、教材 PDF 引用、练习数据文件。

【启动方式（3选1）】

  方法一：双击 启动服务器.bat（推荐 ✅）
    → 自动用 Python 启动 HTTP 服务器，浏览器自动打开
    → 需要系统已安装 Python（3.7+）
    → 所有功能正常工作：PDF 查看、数据预览、导入导出

  方法二：命令行手动启动
    → 在此目录打开终端，执行：
      python -m http.server 8000
    → 浏览器访问 http://localhost:8000

  方法三：直接导入 ZIP 包（离线可用）
    → 双击 index.html 打开（会显示引导页）
    → 点击「导入题目包」按钮，选择 .zip 文件
    → 数据将存储到浏览器本地数据库

【重要说明】
  ⚠ 请勿直接双击 index.html 打开！
  ⚠ file:// 协议会导致数据加载失败（浏览器安全策略）
  ⚠ 推荐使用「启动服务器.bat」或命令行启动 HTTP 服务器

【项目文件结构】
  competition-training/
  ├── index.html              # 主程序
  ├── questions.json          # 题目数据（56题）
  ├── jszip.min.js            # ZIP 处理库（本地版，无需联网）
  ├── 启动服务器.bat           # 一键启动脚本
  ├── README.txt              # 本说明文件
  ├── book/                   # 教材 PDF
  │   ├── 测绘程序设计（上册）.pdf
  │   └── 测绘程序设计（下册）.pdf
  └── practice-data/          # 练习数据（278个文件）
      ├── ch10/ ~ ch21/       # 上册练习数据
      ├── ch22/ ~ ch61/       # 下册练习数据
      └── z2022/ ~ z2025/     # 真题数据

【数据备份与迁移】
  导出：管理后台 → 导出完整包 (ZIP)
  导入：导航栏 → 导入题目包 → 选择 ZIP 文件
  
  注意：IndexedDB 存储空间受浏览器限制（通常 500MB-2GB）
